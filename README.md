# 📚 LMS Clone (PERN Stack)

A full-stack Learning Management System (LMS) clone built using the PERN stack (PostgreSQL, Express, React, Node.js).
This project focuses on building core LMS functionalities along with backend integration.

---

## 🚀 Tech Stack

* Frontend: React.js
* Backend: Node.js + Express.js
* Database: PostgreSQL
* Version Control: Git & GitHub

---

## ✨ Features

* User Authentication (Login / Signup)
* Dashboard UI
* Course Listing & Management
* Responsive Design
* Backend Integration (in progress)
* PostgreSQL Integration (in progress)

---

lms-clone/

## ⚙️ Installation & Setup

### 1. Clone the repository

git clone https://github.com/your-username/lms-clone.git
cd lms-clone

### 2. Install dependencies

Frontend:
cd client
npm install

Backend:
cd ../server
npm install

---

## 🔑 Environment Variables

Create a `.env` file in the server folder:

PORT=5000
DATABASE_URL=your_postgresql_connection_string

---

## ▶️ Run the Project

Start backend:
cd server
npm start

Start frontend:
cd client
npm start
